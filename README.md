# Planets — CPU Raycaster Preview

This repository contains a small CPU raycaster project that renders a miniature planetary system (sun, planets, moon, rings) written in Rust.

Quick start
-----------

- Install Rust (rustup) and ensure `cargo` is on your PATH.
- Build and run in release mode for best performance:

```powershell
cargo build --release
cargo run --release
```

Notes
-----
- The project uses `minifb` to create a window and a CPU-based raycaster for rendering.
- If `Sistema_solar.mp4` doesn't play in the README on GitHub, you can download it from the repository and play locally.
